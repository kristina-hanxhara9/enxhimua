# enxhithemuaa

London Pro Makeup & Hair Artist site.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy

Pushing to `main` builds the site and deploys it to GitHub Pages via
`.github/workflows/deploy.yml`, available at
`https://<owner>.github.io/enxhimua/`.
